# RGI 7.0 Cloud-Native Mirror Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, preview and publish an unofficial, cloud-native mirror of RGI 7.0 (five GeoParquet files, one multi-layer PMTiles archive, a Portolan catalog) to `s3://lqgentner/rgi`.

**Architecture:** A Python package `rgi_catalog` (run under pixi) downloads pinned upstream zips, assembles one table per feature kind, fixes documented upstream errors, writes GeoParquet through `gpio`, tiles the GeoParquet files with tylertoo, and renders the committed `catalog/` from tracked metadata plus a committed build record. Data bytes live in a git-ignored staging tree laid out like `catalog/`. A local overlay server previews both as one tree before the template's `tools/publish.py` and `tools/upload_data.py` upload them.

**Tech Stack:** pixi (conda-forge + PyPI), Python 3.13, geopandas/pyogrio/shapely/pyarrow, geoparquet-io (gpio) 1.7.0, tylertoo 0.8.0 (tippecanoe 2.79 as the fallback), DuckDB, jinja2, PyYAML, rashid `>=0.3.0,<0.4.0`, pytest, ruff, pyrefly.

**Spec:** `docs/superpowers/specs/2026-10-22-rgi-mirror-design.md`. Read it fully before any task; section numbers below (§) refer to it.

## Global Constraints

- Values never change except by the fixes in spec §5.3. Restructuring (folding side tables into columns) is allowed. Floats stay float64. Integer narrowing only when lossless, asserted by the build.
- Attributes come from `-attributes.csv`; geometries from the shapefiles; joined on `rgi_id`; build asserts identical ID sets and float agreement within `1e-12`.
- `rgi_id` is never altered or re-minted.
- File names: `v7.0/{collection}/rgi7.0-{collection}.parquet`; archive `v7.0/glaciers/rgi7.0.pmtiles`.
- Collections: `glaciers`, `complexes`, `centerlines`, `intersects`, `regions`. Each is a single-file collection (no items).
- GeoParquet: version 2.0 (fall back to 1.1 only per Task 7's reader check), zstd level 15, Hilbert order, bbox covering column, row group size ≤ 150,000 (exact value decided at the Task 7 checkpoint), EPSG:4326, 2D.
- Mirror revision string: `7.0-r1`, `7.0-r2`, …; collection `version` field and git tag carry the same string.
- Every README and every catalog/collection description states near the top that this is an **unofficial mirror, not endorsed by the RGI Consortium**, that RGI at NSIDC is the authoritative source, and that citation and credit belong to the RGI Consortium, with the citation inline.
- Dataset citation: *RGI 7.0 Consortium, 2023. Randolph Glacier Inventory - A Dataset of Global Glacier Outlines, Version 7.0. Boulder, Colorado USA. NSIDC: National Snow and Ice Data Center. doi:10.5067/f6jmovy5navz.*
- Providers: `RGI Consortium` (`producer`, `licensor`) first; `Luis Gentner` (`host`, url `https://github.com/lqgentner/rgi-catalog`) last. `via` → `https://nsidc.org/data/nsidc-0770/versions/7` (`text/html`). License `CC-BY-4.0`.
- Publish target: `write_prefix: s3://lqgentner/rgi`, `public_base: https://data.source.coop/lqgentner/rgi`, profile `source-coop`, endpoint `https://data.source.coop`. Human-facing links use `https://source.coop/lqgentner/rgi`.
- Never commit `.parquet`, `.pmtiles`, `.zip` or other data (template `.gitignore`). Staging lives in `staging/` (git-ignored), downloads in `.cache/`.
- `catalog/` is generated by `render`; never hand-edit it. Do not widen `ACCEPTED` in `tests/test_conformance.py` without a row in `docs/conformance.md` and an issue.
- Code style (as in the author's other repos): every module starts with `from __future__ import annotations`; NumPy-style docstrings without Examples/Notes; ruff; pyrefly strict over `src/` and `tests/unit/`; conventional commits.
- Nothing is imported from `deep-glacier-mapping`, `glace-catalog` or `freezebase`.
- Upload, checksum source choice, row group size, `display_name` rules and style plan are **author checkpoints**: stop and ask at the steps marked CHECKPOINT.

## Review Focus

1. **Glaciers missing from a side table** (no hypsometry row, no complex, no submission row, no RGI6 link) must keep their row with nulls/empty lists, never vanish in a join. Pinned in Task 6.
2. **Mixed-case real names must not be re-cased** (`McCall Glacier`, `Hintereisferner`, Cyrillic names); only ALL-CAPS names are re-cased. Pinned in Task 5.
3. **Garbled text outside `glac_name`** (submitter and analyst names, region names) gets the same repair. Pinned in Task 4.
4. **A truncated or changed download** must be refused and not left in the cache looking verified. Pinned in Task 2.
5. **Rebuilding from the same inputs must give the same bytes**, so checksums and the render-drift test are stable. Pinned in Task 7 (if gpio output is not byte-stable, the test documents it and Task 10's record still hashes the actual bytes).
